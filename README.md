# PAP-Raul-D-ria---Intelig-ncia-Artificial-For-Kids
Este repositório é direcionado para o Prova de Aptidão Profissional da Escola Profissional Raul Dória. A ideia seria construir uma Inteligência Artificial direcionada para alunos e professores da 1ª à 4ª classe, uma IA adaptativa aos utilizadores, ou seja, diminui e aumenta o nível de dificuldade das perguntas dependendo da resposta recebida.
